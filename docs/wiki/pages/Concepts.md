type:: concept
summary:: The vocabulary: graph, page, block, journal, reference, tag, task, property, namespace, alias, op — and the editor's two states.
tags:: concept

- **Graph**: one person's whole dataset — pages, blocks, assets, settings. One graph per server (`docs/PLAN.md` §17). It lives in `graph.sqlite` in the data directory; see [[Architecture]].
- **Page**: a named container of top-level blocks. Two kinds: ordinary pages and journals. Identity is the name folded — NFC-normalised, trimmed, whitespace collapsed, lower-cased (`normalizePageName`, `packages/core/src/page-name.ts`) — so `[[getting started]]` and `[[Getting Started]]` are one page. A page's URL is `/page/<name>`.
- **Block**: one bullet. It has markdown `content` (which may span lines: a heading, a code fence, a table, several paragraphs), an optional task `marker` and `priority`, a `collapsed` flag, `properties`, and a place in its page's tree: a parent and a fractional-index order among siblings (ADR 004). Every block has a 14-character id such as `1k7f3q9xz2hav4`, written in markdown as a trailing ` ^id` on its first line. Agents address blocks by these ids.
- **Journal**: a page that carries a day. Stored under its ISO name (`2026-09-07`) and displayed in a format you choose. See [[Journals]].
- **Reference**: a derived link from a block to a page (`[[Page]]`, `#tag`, or a `tags::`/`alias::` property value) or to a block (`((id))`, `{{embed ((id))}}`). References are computed from content, never stored as truth, and rebuilt whenever a block changes. A page shows what points at it under "Linked references". See [[References and tags]].
- **Tag**: a page, referenced with `#tag` or `#[[multi word tag]]` instead of `[[...]]`. There is no separate tag object (ADR 017): `#guide` and `[[guide]]` point at the same page. A page can carry tags too, through its `tags::` property — that is how this wiki's pages are grouped.
- **Task**: a block whose first word is a marker: `TODO`, `DOING`, `DONE`, `WAITING`, `CANCELED`, plus `LATER` and `NOW`, kept from Logseq. Every task automatically references a `Task` page, derived from the marker and never written into your text. See [[Tasks]].
- **Property**: a `key:: value` line. On a block, property lines follow the first line; on a page, they sit at the top of the file before the first bullet. Keys are lower-case with `-` (an `_` is rewritten on import); values are strings. `alias::` and `tags::` are comma-separated lists of page names. A bare value under any other key is *not* a page reference: `type:: guide` creates no page, `type:: [[guide]]` does (`docs/spec/markdown-grammar.md` REF-2, a deliberate departure from Logseq).
- **Namespace**: a `/` inside a page name, `Projects/Aurora`. Ancestors are implied, never stored; the page shows its children as a tree and lists show the short form. Creating `A/B/C` implies `A` and `A/B` for navigation without creating them as pages.
- **Alias**: `alias:: garden` on a page named `Zahrada` makes `[[garden]]` resolve to it and counts both names in its backlinks (fixed in B-55). Aliases resolve inside the app and over the API; opening `/page/garden` directly in the browser does not resolve one yet (the client looks up `page.key` only).
- **Op**: every write — from the editor, the API, an agent, an import or another device — is a list of small operations, each on one field of one entity, appended to a log with a hybrid logical clock. That log is what sync ships and what `nooklet verify` replays. See [[Sync]] and [[Architecture]].
- ## The editor's states
  - The shortcuts on [[Keyboard shortcuts]] are conditional on these, so they are worth knowing by name.
  - **Editing** (`editorFocused`): one block has the cursor. There is exactly one editing surface in the app — a CodeMirror 6 editor moved into whichever block you click (ADR 006). The block being edited shows its raw markdown with live-preview decorations; every other block is rendered.
  - **Block selection** (`blockSelected`): press Escape while editing, or Cmd/Ctrl+click a block. No cursor; one or more whole blocks are selected. Shift+Up/Down extends the selection, Enter returns to editing, Backspace or Delete deletes, Cmd/Ctrl+C copies the selection as outline markdown, Tab and Shift+Tab indent or outdent all of it, Escape clears it.
  - **Zoomed** (`zoomed`): Cmd/Ctrl+. makes the current block the top of the view; the breadcrumb takes you back up, Cmd/Ctrl+Shift+. goes up one level.
